# SMB2011-fan-episodes

A custom collection of fan-made episodes for Super Mario Bros. (2011). This project showcases custom level design, asset optimization, and configuration file modifications.

---

### 🛠️Technical Details & Optimization

* 🔍 **File Analysis:** I created these levels by opening and studying the game's internal configuration files. I modified coordinates and object IDs to build custom maps without any official instructions.<img src="coin.png" width="50" align="right" alt="Coin">
* ⚡ **Performance:** The gameplay GIF at the bottom is set to a maximum width of 800px. This makes the GitHub page load faster and prevents lag on phones and slow computers.

---

### 🧠 Level Design Concept

This project provides hands-on experience in the following areas:
* 🗺️ **Level Construction** – Mastering pacing, difficulty curves, and player flow.
* 🧪 **Playtesting** – Comprehensive testing to ensure precise collision handling and glitch-free gameplay.
* 🎨 **Graphic Design** – Using *IbisPaint* to design and implement custom backgrounds and floor textures.
* 💡 **Creativity** – Implementing advanced design ideas and transforming engine limitations into gameplay features.

---

### 🧱 Engine Constraints

<img src="mushroom.png" width="50" align="left" alt="Mushroom"> Everything is built straight inside the original editor's strict constraints. Overcoming these limitations to deliver polished gameplay was the core challenge of the development process.

### 📦 Installation Guide

<details>
<summary>📖 Click here to see how to install the episodes</summary>

1. **Download the Base Game:** First, get the official Super Mario 2011 engine here: [Official Legacy Site](http://legacy.pi-dev.com/super-mario)
   * *Note:* The site uses HTTP (unsecured) and your system might trigger a warning. It is a **false positive** due to a lack of digital signatures. The files are safe to use.
2. **Download the episodes** from the links provided in the section below.
3. **Move** the unpacked folders directly to this directory:  
   `Data` ➜ `Levels`
4. **Launch** the game, navigate to the **"Episodes"** section, and the custom levels will be ready to play.

> ⚠️ **CRITICAL NOTE:** If you do not place the folders strictly inside the `Levels` directory, the game will fail to detect them. Ensure the path is correct.
</details>
